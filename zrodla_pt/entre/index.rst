    Brenna, arquidiocese de Katowice
Local de criação dos esquemas:
    Diocese de Gliwice
Grupo-alvo:
    Retiro aberto para adultos e~crianças
Descrição do retiro:
    O retiro conduz os participantes pela experiência de estar "entre": entre o~que é conhecido e~o~que ainda não foi descoberto; entre a~fé pessoal e~a~fé comunitária; entre receber e~dar. A~partir da imagem de Deus Criador, que constrói um espaço para o~ser humano, passamos pela desconstrução e~reconstrução da imagem de Deus em direção à vocação de cocriar espaços de fé para os outros. Este caminho, inscrito na simbologia das letras Alef e~Bet, conduz à palavra "Awinu" -- Pai nosso --, onde a~relação íntima com Deus e~a~comunidade dos crentes se tornam uma só realidade.
