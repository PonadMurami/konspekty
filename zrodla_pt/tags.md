# Etiquetas de esquemas (`sphinx_tags`)

Este arquivo é uma **lista de etiquetas canônicas** usadas nos esquemas (`.rst`) através da diretiva:

```rst
.. tags:: etiqueta1, etiqueta2, etiqueta3
```

## Regras

- **Formato**: letras minúsculas, palavras unidas por hífen (`-`).
- **Separação**: por vírgulas (formato exigido por `sphinx_tags`).
- **Identificador vs etiqueta**:
  - **Identificador** da etiqueta é o texto entre backticks (ex. `espirito-santo`) — mantenha-o em **ASCII** (sem caracteres especiais), pois é uma chave técnica (links/URLs, compatibilidade de ferramentas).
  - **Etiqueta** (ex. "Espírito Santo") é apenas para humanos — pode conter caracteres especiais.
- **Eixo do encontro (o mais importante!)**: etiquetamos apenas o que é o **eixo** do encontro (tema/método principal), não o fundo.
  - Se o tema aparece "de passagem" (ex. há oração no início, mas o encontro não é sobre oração) — **não adicione** essa etiqueta.
  - Para métodos: adicione a etiqueta do método apenas se for uma **ferramenta chave de trabalho** no encontro (e não simplesmente "conversamos").
- **Seleção**: geralmente **3–8 etiquetas** por arquivo:
  - 1–3 etiquetas de conteúdo (sobre o que é o encontro)
  - 1–3 etiquetas de método (como trabalhamos)
  - 0–2 etiquetas de tipo/caráter
  - (opcional) 1 etiqueta auxiliar
- **Não etiquetamos nomes de ciclos de retiro** (isso já decorre da estrutura de diretórios em `zrodla/`).
