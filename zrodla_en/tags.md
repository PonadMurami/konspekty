# Outline tags (`sphinx_tags`)

This file is the **canonical list of tags** used in outlines (`.rst`) via:

```rst
.. tags:: tag1, tag2, tag3
```

## Rules

- **Format**: lowercase, words joined with underscores (`_`).
- **Separators**: commas (required by `sphinx_tags`).
- **ID vs label**:
  - The **tag ID** is the text in backticks (e.g. `duch_swiety`) — keep it **ASCII-only** (no diacritics), because it is a technical key (URLs, tooling).
  - The **label** (e.g. “Holy Spirit”) is for humans and can contain any characters.
- **Main axis (most important!)**: tag only what is the **core** of the meeting (main topic / main method), not background.
  - If something appears “incidentally” (e.g. prayer at the start, but the meeting is not about prayer) — **do not** add that tag.
  - For methods: add a method tag only if it is a **key working tool**, not just “we talked”.
- **Typical selection**: **3–8 tags** per file:
  - 1–3 content tags (what the meeting is about)
  - 1–3 method tags (how you work)
  - 0–2 type tags (meeting character)
  - (optional) 1 helper tag
- **Do not tag retreat cycle names** (these come from the folder structure).
